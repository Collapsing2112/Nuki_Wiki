#### **以下是部分您可能提问的问题，我们为您进行解答：**

  Q ：这里什么网站？
  A ：NukiWiki是由Unknown08编写的，用于对初学BOT、Python的用户提供的Wiki教学网站<br>

  Q ：Nuki Wiki现在还在更新吗？
  A ：是的，Nuki Wiki现在还在进行更新，并于近日正式发布了2.0的重置版本！<br>

  Q ：我能在这里学到什么？
  A ：NukiWiki将为您提供Python、Nonebot、Napcat的基础教学内容，同时也会提供拔高拓展的具有难度的知识，未来我们或许会添加C++、Godot相关内容<br>

&emsp;  Q ：需要编程基础吗？
  A ：不需要，该Wiki只需要您拥有以下内容：
    1、知道Python、C++、Java等编程语言的区分差别
    2、对电脑等电子设备具有最基本的了解，比如会使用键盘、鼠标等<br>

&emsp;  Q ：可我注意到部分文章貌似确实比较难，我要全部学习吗？
  A ：无需全部学习，当你涉及到这方面知识需要进行学习时，可以前来查看。我们为文章进行了分级处理，您可以跟分级考虑是否学习。<br>

&emsp; Q ：可我注意到部分文章貌似确实比较难，我要全部学习吗？
&emsp; A ：无需全部学习，当你涉及到这方面知识需要进行学习时，可以前来查看。我们为文章进行了分级处理，您可以跟分级考虑是否学习。

> #### 文章分级
> - [S] 上手难度高，难学习，需要有充足的编程基础
> - [A] 上手难度较高，较难学习，适合想来挑战自己的用户查看
> - [B] 上手难度一般，较易学习，主要提供给编程基础不是特别好，想要练习的用户查看
> - [C] 上手难度低，易学习，主要提供给没有编程基础的用户学习编程基础
> - [?] 作为开篇的介绍，或首页，将不给予任何分级，以方便用户确认这些内容是否合适学习


&emsp; Q ：我可以提供相关的教学内容吗？
&emsp; A ：当然可以！本网站使用的是Github静态部署，你可以通过提交文章的方式进行投稿，审核通过后，你的文章将被上架本Wiki
